MONO · 清掉旧的 Service Worker 与缓存
为什么需要这一步
  • 早期版本的离线缓存策略会优先返回旧代码，普通刷新拿不到新版本。
  • 点一次下面的按钮即可彻底清除并重新载入。

如果按钮没反应（手动方式）
  1. 桌面浏览器：按 F12 → Application → Storage → Clear site data，然后 Ctrl+Shift+R。
  2. 手机 Chrome：地址栏设置 → 网站设置 → 存储 → 找到本站 → 清除并重置。
  3. 手机 Safari：设置 → Safari → 高级 → 网站数据 → 删除本站数据。
  4. 或在控制台执行：
    navigator.serviceWorker.getRegistrations().then(r=>r.forEach(x=>x.unregister())).then(()=>caches.keys()).then(k=>Promise.all(k.map(x=>caches.delete(x)))).then(()=>location.reload())
